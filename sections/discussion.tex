\paragraph{Beyond PEFT}
\ac{PEFT} is a convenient tenant because it reuses the resident model
backbone and adds comparatively little state. More generally, \sys{} can
schedule any backbone-sharing workload that fits in memory and decomposes
into short, predictable units that complete within rank-local slack.
Identifying additional workloads with these properties is future work.
